# Release 交付要求

每次发布完整套件，必须提供可安装或可运行的附件：

1. Android：已签名、可直接安装的 APK，沿用现有签名以支持升级。
2. Linux：包含完整依赖目录的 x64 TAR.GZ，保留可执行权限。
3. Windows：包含 EXE 和完整依赖目录的 x64 ZIP。
4. ESP32-S3：包含 bootloader、分区表、应用 BIN、实际 flash_args、Linux/Windows 烧录脚本及中文地址说明的 ZIP。不能只提供 ELF 或源码；默认分段烧录保留 NVS。
5. SHA256SUMS：覆盖所有完整安装包/固件包。Gitee 如使用分卷，还须包含分卷校验与合并说明。

发布说明分别标明 Android、Desktop、固件版本、对应提交、适用平台及验证范围。GitHub 和 Gitee 同步，保留仓库现有可见性。仅上传源码不能视为完成 Release。

发布前验证 APK 签名与版本、固件镜像/分区适配、两种桌面包的启动测试；发布后核对附件、文件大小、哈希（平台提供时）与标签提交。构建通过不等于手机安装、实板烧录或 CAN 实测通过。
