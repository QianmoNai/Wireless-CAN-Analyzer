# 电机控制面板（App 1.1 / BLE 协议扩展）

## 支持范围

| 电机 / 电调 | 模式 | 快捷操作 |
| --- | --- | --- |
| 大疆 M3508 + C620 | CAN 电流给定，raw ±16384 | 分组发送、整组零给定、0.5 秒点动 |
| 大疆 M2006 + C610 | CAN 电流给定，raw ±10000 | 分组发送、整组零给定、0.5 秒点动 |
| 大疆 GM6020 | 手册定义的 CAN 电压给定，raw ±30000 | 分组发送、整组零给定、0.5 秒点动 |
| 达妙 DM4310 / 通用经典协议 | MIT、位置速度、速度、力位混合 | 使能、失能、清故障、设置零点、读写运行模式、点动 |

大疆 CAN 模板不提供电调本身没有的“速度 / 位置设定”命令。若需速度或位置闭环，应在 ESP32 上根据反馈另行实现控制器，不能用电流数值冒充速度。

达妙其他型号使用可配置量程模板，不声称已验证所有型号。DM4310 的预填 MIT 量程依据官方 STM32 示例为 P_MAX=12.5 rad、V_MAX=30 rad/s、T_MAX=10 N·m；必须与实际电机参数一致，不同硬件版本可能不同。其他型号的量程默认留空，需填写后才会生成控制帧。力位混合与运行模式寄存器需要对应固件支持。

## 使用顺序

1. 安装新版 APK，并更新 ESP32 固件。App 等待设备报告实际波特率后才能使用电机快捷指令；旧版固件没有该报告。
2. 选择电机类型；大疆选择分组，达妙填写 CAN ID、反馈 Master ID 及模式。ID 框是十六进制，大疆槽位编号是十进制。
3. 点击波特率「应用」。大疆使用 1 Mbit/s；达妙默认通常是 1 Mbit/s，以电机现有配置为准。该操作只改变 ESP32，重启后恢复固件默认 1 Mbit/s。
4. 达妙选择模式只改变报文编码，不会自动写电机。可用「读取运行模式」核对，再用「写入运行模式」修改 0x0A 寄存器；不会发送保存 Flash 命令。运行模式回复显示在面板内。
5. 填写目标并查看报文预览。「发送一次」只发送一帧；「点动 0.5 秒」由 ESP32 约 100 Hz 发送，结束时追加大疆整组零给定或达妙失能帧。达妙需要先单独使能；点动结束后失能，下次需要重新使能。
6. 查看 CAN ACK 和实际电机反馈。ACK 仅代表总线上有节点应答，不能证明目标电机已经执行。

MIT 快捷参数填充包含纯力矩、阻尼、位置伺服，选择后不发送。设置零点会改变坐标参考，App 会显示包含电机 ID 的确认框。运行模式切换也可能影响电机状态，应在电机静止时操作。

大疆报文按四个电机一组编码，**0 不是忽略槽位，而是向该电机给零值**。C620/C610 的 ID 5–8 与 GM6020 的 ID 1–4 都可能使用 0x1FF；混合总线不能只按品牌区分，需规划 ID、分组并避免其他控制器同时写同一组。

## 编码

- 大疆：四个有符号 16 位大端槽位。C620/C610 分组 ID 0x200、0x1FF；GM6020 分组 ID 0x1FF、0x2FF，后者最后槽位保留为 0。
- 达妙 MIT：基础 CAN ID，位置 16 位，其余速度/Kp/Kd/扭矩各 12 位；Kp=0…500，Kd=0…5。其余范围由面板量程指定，按官方示例截断量化。不能用全零字节代替“零力矩”，全零会编码到负量程端点。
- 达妙位置速度：基础 ID+0x100，两个 little-endian float32（位置、速度上限），DLC 8。
- 达妙速度：基础 ID+0x200，一个 little-endian float32（速度），DLC 4。
- 达妙力位混合：基础 ID+0x300，float32 位置 + uint16(速度上限×100) + uint16(电流比例×10000)，均小端，DLC 8。
- 达妙使能/失能/零点/清故障：所选模式偏移 ID，前 7 字节 FF，末字节分别 FC/FD/FE/FB。
- 运行模式：向 0x7FF 写 `[CANID_L,CANID_H,55,0A,模式 uint32 LE]`，模式 1/2/3/4；读取用 `[CANID_L,CANID_H,33,0A]`。收到 Master ID 返回的寄存器回复后才显示“电机反馈运行模式”。

## 点动边界与反馈

默认上电不再发送旧的 0x123 测试帧，避免与电机 ID 冲突。点动期间不接受其他普通控制命令；停止请求可以优先排队到 BLE 当前写操作之后。固件使用独立计时，不依赖手机定时发送。BLE 断开、收到停止请求或 CAN TX 失败时中止重复发送，并尝试发送结束帧。

这不是硬件急停。如果 CAN 总线断线或 bus-off，结束帧可能无法送达；App 报告失败或未知，不会声称电机已停止。新界面没有自动重连后恢复运动、没有上电自动使能。

大疆反馈显示转子角度、rpm、raw 电流反馈及可用温度；不擅自换算输出轴减速比。达妙按 Master ID 和反馈低 4 位电机 ID 匹配，显示位置、速度、扭矩、MOS/电机温度与驱动状态，要求量程正确。使用唯一 Master ID 区分低 4 位相同的电机。串口 RX 日志限制到约 10 Hz，防止 1 kHz 电机反馈堵塞 UART；BLE 仍尝试推送全部帧，控制结果使用独立优先队列。监控不是无损抓包，丢弃有计数。

## 当前用户配置

用户确认当前电机为 C620/M3508、ID 1：控制帧 0x200，反馈帧 0x201。App 默认选择 C620、第一组及观察 ID 1。达妙新安装默认 CAN ID 0x001、Master ID 0x000；升级安装保留已有保存配置，若此前保存为 0x11，请在面板改为 000。GM6020 ID 1 对应控制帧 0x1FF、反馈帧 0x205。


## App 1.9 监控版状态查询

依据官方 `motor-control-routine/SocketCan控制例程/Python例程/damiao_socketcan.py` 的 `refresh_motor_status`（本次查阅时第 338–340 行），发送标准 ID 0x7FF，DLC 4，数据 `[CANID_L, CANID_H, CC, 00]`。官方 DM-J4310-2EC V1.1 手册 V1.3 的 Feedback Mechanism 一节说明反馈为请求响应机制。

App 只将这一个固定查询加入发送允许列表；不恢复其他控制命令。调度、停止条件、默认关闭和频率见当前 README。此查询需要具体电机固件支持，尚未用真实达妙电机完成应答验证。
