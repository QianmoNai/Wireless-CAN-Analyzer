# GPIO3 通信指示灯

当前源码固件 1.22.0 新增，适用于无线 CAN 分析仪 v1PRO 的 ESP32-S3 板。

## 接线

```text
GPIO3 ── R5 1kΩ ── LED1 阳极 A
  │                 LED1 阴极 K ── GND
  └──── R6 10kΩ ── GND
```

LED1 为普通绿色 0805 LED，高电平点亮。10kΩ 是 GPIO3 到 GND 的下拉，1kΩ 是 LED 串联限流电阻。

## 行为

| 状态 | 灯光 |
| --- | --- |
| 上电、无线未连接、断开连接 | 熄灭 |
| 无线连接可用、CAN 空闲 | 常亮 |
| 本机收到 CAN 帧或 CAN 成功发送 | 短灭约 50ms 后恢复点亮 |
| 持续 CAN 收发 | 合并活动，亮至少 150ms，最多约每秒 5 次闪烁 |

蓝牙以通知订阅可用为准；Wi-Fi 以通过认证的上位机 TLS 会话为准；双机 A/B 以已建立可转发的对端连接为准。只有连上路由器或保存过配对信息，不会被显示为已连接。断连清除待闪烁活动，重连后从常亮开始。

活动直接读取 CAN 接收成功计数与发送成功计数，涵盖普通监控、达妙查询和双机转发；失败发送、软件入队和无线心跳不触发。该灯反映本机 CAN 活动，不能证明上位机逐帧接收或双机端到端无丢帧。高帧率下不会逐帧闪烁。

CAN owner 任务周期更新灯光；不在 CAN 中断里操作 GPIO，不增加任务、队列或逐帧延时。指示灯不依赖 LCD 任务、方向、亮度或蜂鸣器。实际闪烁时刻受任务调度影响。GPIO 初始化或写入失败时，仅停用指示灯，CAN 和无线通信继续工作。

## 构建

`bash firmware/idf.sh menuconfig` → `CAN analyzer status LED` → `GPIO3 communication indicator (active high)`，对应 `CONFIG_CAN_STATUS_LED`。

ESP32-S3 默认启用，可独立于 `CONFIG_CAN_LOCAL_PANEL` 关闭。旧 ESP32 目标始终不配置 GPIO3，保留原有串口引脚用途。App 协议未变，无需更新 Android 或 PC 软件。

现有 1.21.0 Release 和此前的项目备份不包含此新增功能，需要使用更新后的源码构建固件。主机测试验证 GPIO 输出及闪烁逻辑；实物亮度、接线和无线/CAN 联调仍需上板确认。

1.23.0：指示灯活动计数跟随屏幕的数据选择；CAN 模式按 CAN 成功收发闪烁，UART 模式按串口收发字节活动闪烁。
