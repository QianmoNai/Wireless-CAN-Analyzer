# 性能调整与测量

## App 1.18.2 性能调整

此次调整保持现有 CAN 指令和 BLE 协议。ESP32 的查询、续租和停止逻辑不随页面绘图改变。

| 调整 | 当前实现 | 收益与限制 |
| --- | --- | --- |
| 按屏幕节奏绘图 | 每个有效采样立即解码、记录；数值、曲线和详情报文视图通过同一个 `requestAnimationFrame` 合并更新。100ms 状态计时器也走同一调度器。 | 同一屏幕周期内避免重复绘图；可见变化最多等待下一次屏幕刷新。隐藏页面停止绘图，恢复时更新最新状态。 |
| 有界接收和批量跨桥 | 每通道普通队列512条、界面管理队列64条；每轮最多处理128条，16ms 调度。普通数据最多一个 WebView 调用待完成。查询控制由独立线程和128条队列处理。 | 限制突发输入和页面变慢时的积压。普通队列满时丢最旧数据并计入 App 丢帧；管理队列满时明确报错并断开。接收年龄包含排队和跨桥耗时。 |
| 首页合并和增量更新 | 摘要、温度更新在75ms 窗口合并；保留1秒心跳和过期检查。固定元数据缓存，卡片只有内容变化时才写 DOM，顺序变化时才重排。 | 减少多电机、多通道下的重复快照和卡片写入；连续更新最多增加每层75ms 的合并等待。配置和页面切换仍立即更新。 |
| 报文历史环形缓冲 | CAN 监控 RX/TX 分开保留；详情 RX 单独保留。写入为 O(1)，仅在读取显示快照时合并顺序。暂停使用独立快照。 | 避免每帧移动历史数组；显示快照仍按保存上限占用内存，不能用作无损抓包。曲线原有60000点/60秒上限与峰值保留规则继续生效。 |
| 构建目录和产物 | 按项目路径、目标隔离缓存，构建锁防并发覆盖。Android 清理 class/dex，验证签名后原子替换 APK；IDF 默认避开非 ASCII 构建路径，并迁移旧 sdkconfig。 | 防止旧类、旧 dex 和路径问题混入产物；首次缓存迁移需重新编译。显式覆盖构建目录时由调用者选取合适路径。 |
| 页面相关连接优先级 | 查看 CAN 监控或详情立即请求 HIGH；首页、配置页、设置页及非活动通道请求 BALANCED。降级延迟500ms，API 拒绝后1秒重试。 | 减少无高吞吐显示需求时的高优先级请求；快速切换页面避免频繁降级。Android 与外设协商结果决定实际间隔，省电幅度需手机实测。 |

### App 验证

`bash scripts/test-host.sh` 覆盖队列溢出、管理优先、并发接收、连接优先级、环形历史、构建锁、旧产物清理、配置迁移和签名失败保护。

`tests/test_ui_performance.py` 验证1000个有效采样合并为一次屏幕绘图，1000条采样仍完整记录，保留中间温度峰值；32电机在线摘要和四个温度分包合并为一次页面快照；重复首页数据对电机卡片产生零 DOM 变更。过期数据、部分温度批次、页面优先级提示也有回归覆盖。

已有界面回归继续覆盖暂停、过滤、排序、分页、配置导入导出、多通道、电机查询、IMU 和全屏曲线。这些结果来自主机测试和模拟 Android 桥的 Chromium 测试；不能推算成某款手机的帧率、BLE 吞吐或功耗改善比例。

## ESP32 固件 1.20.3 页面切换

进入设置和长按返回均需刷新整屏。ESP-IDF 6.0.2 的 `lcd_spi_post_trans_color_cb` 丢弃用户回调的布尔返回值；此前 `color_done` 只通知任务并返回唤醒标记，没有请求 ISR 调度，导致条带之间额外等待。现在在任务被唤醒时显式调用 `portYIELD_FROM_ISR()`，不再依赖驱动传播返回值；SPI 仍为 20MHz。

2026-10-10，在同一台 ESP32-S3 上自动执行两次进入设置、两次返回总览。条件为 180° 竖屏、Wi-Fi 模式、每帧 20 条带，测试未发送 CAN 指令。两轮只改变 DMA 唤醒处理，使用相同的 240ms 页面动画；计时从开始绘制到最后一次 DMA 完成，原始记录见 [帧耗时 CSV](panel-page-timings.csv)。

| 指标 | 修正前 | 修正后 |
| --- | --- | --- |
| 完整帧样本 | 12 帧 | 20 帧 |
| 每帧耗时范围 | 90.27～102.93ms | 50.28～51.03ms |
| 平均每帧耗时 | 97.05ms | 50.57ms |
| 按平均耗时折算的连续整屏帧率 | 10.3 帧/秒 | 19.8 帧/秒 |

正式版另将页面动画改为缓入缓出，降低起步位移；菜单与主题仍采用缓出。计时验证了 CPU/SPI 提交与 DMA 完成速度，不能替代对实体屏幕观感的确认，也不代表 CAN 高负载下的固定帧率。

`tests/test_panel_dma.py` 直接提取实际回调，在忽略返回值的 SPI 模拟环境中检查立即调度；旧实现会失败，修正后通过。实机计时模式默认关闭，启用和恢复方式见 [测试说明](../tests/README.md)。
