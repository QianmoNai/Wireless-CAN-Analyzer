# 硬件

目标硬件：ESP32-S3 Mini、SN65HVD230、172×320 ST7789 SPI 屏、三个按键、3V 有源蜂鸣器。

完整 GPIO 表、背光与蜂鸣器的 MOSFET 控制接线见 [本机面板说明](../docs/LOCAL_PANEL.md)。CAN 模块使用 3.3V，CTX 接 GPIO4，CRX 接 GPIO5；模块、开发板与总线设备必须共地。

通信绿灯使用 GPIO3：经 1kΩ 接普通 0805 LED 阳极、阴极接 GND；GPIO3 另经 10kΩ 下拉至 GND。固件 1.22.0 起默认提供连接常亮与 CAN 活动闪烁，见 [指示灯说明](../docs/STATUS_LED.md)。

按当前设计，两个 CAN 插座连接同一条总线，但引脚序号不同：

| 接口 | 1 脚 | 2 脚 |
| --- | --- | --- |
| CN6 | CANH | CANL |
| CN5 | CANL | CANH |

制作线束时按 CANH/CANL 信号名称对应连接，不能仅按引脚序号直连。

原理图及 PCB 原始工程尚未纳入仓库。外部降压模块型号、输入电压范围、USB 与外部供电并接路径，以及裸屏供电与背光限流参数，需要按实际器件核对；代码不能代替这些电气参数。

固件 1.23.0 新增串口数据选择：ESP32-S3 开发板 TX=GPIO43、RX=GPIO44，与外部 3.3V TTL 单片机交叉接线并共地。默认 115200 / 8N1。CAN/UART 同时只转发一种，详见 [UART 接线和使用](../docs/UART.md)。
